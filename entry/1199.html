Methods Assay, extraction, and data processing text

Assay description

mRNA-seq and WGBS-seq of maternal Dnmt3a/3b-null trophoblast; mRNA-seq of maternal Ascl2 KO trophoblast

Extraction protocol

RNA was DNase treated with the DNA-free kit (Life Technologies). Messenger RNA was purified using a Dynabeads mRNA Purification Kit (Life Technologies). Strand-specific libraries were generated using the ScriptSeq v2 RNA-Seq Library Preparation Kit (Epicentre). Genomic DNA and RNA were isolated from the same samples using the Allprep DNA/RNA kit (Qiagen). DNA was bisulfite converted using the Imprint DNA Modification Kit (Sigma). Whole-genome BS-seq libraries were prepared from 25-70 ng genomic DNA, using a post-bisulfite adaptor tagging protocol, as previously described (Peat et al. 2014). Genomic DNA and RNA were isolated from the same samples using the Allprep DNA/RNA kit (Qiagen).

Main topic
This paper investigates the role of DNA methylation in trophoblast development in mice by performing mRNA and DNA methylation profiling of Dnmt3a/3b deficient mutants, revealing that oocyte-derived DNA methylation is a regulator of trophoblast transcription and cell adhesion, partly dependent on silencing of the Polycomb gene Scml2.

Methods Assay, extraction, and data processing text

Assay description

We performed RNA sequencing (RNA-seq) with WGNCA using 30 human placental samples, separated into villous tissue (VT) and decidua basalis (DB) and clinically grouped as follows: (1) early-onset PE (EOPE, n=8); (2) EOPE+FGR (n=7); normotensive, nonanomalous preterm FGR (n=5); idiopathic preterm birth (iPTB, n=5); and uncomplicated term births (TB, n=5).

Extraction protocol

RNA was isolated using TRIzol reagent (Life Technologies), then purified using the RNA Clean-Up and Concentration Kit (Norgen Biotek). RNA libraries for RNA-seq were prepared using using the TruSeq Stranded Total RNA Sample Prep Kit with Ribo-Zero Gold following manufacturer's protocols (Illumina).

Main topic
This study applies transcriptomics with weighted gene correlation network analysis (WGCNA) to clarify placental dysfunction in early-onset preeclampsia (EOPE) with and without fetal growth restriction (FGR), identifying a glycolytic metabolic shift in a subset of EOPE±FGR placental specimens.

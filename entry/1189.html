Methods text

Assay description

To examine gene expression patterns of human trophoblasts expressing constitutively active YAP 5SA Next Generation Sequencing was performed. vCTBs, isolated from pooled placentas from 6-8th weeks of gestation, were transfected with pCMV-flag YAP2 -5SA or as control with pcDNA 3.1(-)plasmid DNA using electroporation following 24h cultivation on fibronectin-coated cell culture dishes. The analyses comprise in total 6 samples, 3 replicates of 3 individual trophoblast cell preparations.

Extraction protocol

RNA was extracted using AllPrep DNA/RNA/miRNA Universal Kit (Qiagen). Sequencing libraries were prepared using the NEBNext Poly(A) mRNA Magnetic Isolation Module and the NEBNext Ultra™ II Directional RNA Library Prep Kit for Illumina (New England Biolabs). Libraries were QC-checked on a Bioanalyzer 2100 (Agilent) using a High Sensitivity DNA Kit for correct insert size and quantified using Qubit dsDNA HS Assay (Invitrogen). Pooled libraries were sequenced on a NextSeq500 instrument (Illumina) in 1x75bp single-read sequencing mode.

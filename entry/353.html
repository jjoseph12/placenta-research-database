Methods Assay, extraction, and data processing text

Assay description

In vitro decidualization was induced from primary endometrialum stromal cells by using progesterone (P4) and cAMP-stimulation. Then, one primary endometrial stromal cells (control) and samples were collected at different time points (Day1-Day5) and subjected to bulk RNA sequencing.

Extraction protocol

DNA and RNA extracted according to the manufacturer’s instructions. RNA-seq libraries preparation using the VAHTS Universal V8 RNA-seq Library Prep Kit for Illumina (Vazyme).

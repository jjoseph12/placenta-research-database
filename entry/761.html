Methods Assay, extraction, and data processing text

Assay description

For E3.5 uterus MeDIP-seq data, we generated biological replicates from 3 young (8-20 week old) and 5 aged (41-49 week old) mice. For E11.5 data, we generated biological replicates of 6 deciduae from 3 litters (2 from each litter) from young mothers (9-10 weeks, n=3) and 10 deciduae from 5 litters of aged mothers (43-47 weeks, 2 deciduae from each litter). Aged E11.5 samples were split into 2 groups: those accompanying embryos that appeared normal (An, n=3) and those with morphologically abnormal embryos (Aa, n=3). One An and one Aa decidua was taken from each litter

Extraction protocol

Genomic DNA was extracted from snap frozen tissue using Qiagen Allprep DNA/RNA mini kit (Qiagen, 80204), according to the manufacturers instructions. DNA libraries were generated using the NEBNext DNA library prep master mix set for Illumina (New England BioLabs E6040L), according to the manufacturerâ€™s instructions till the end repair stage, using 1.5Âµg of sonicated DNA. Unamplified DNA libraries were subjected to methylated DNA immunoprecipitation (MeDIP) to isolate fragments of methylated DNA. Briefly, library DNA was denatured at 99oC before incubation with anti-5mC antibody (Eurogentec BI-MECY-0100) for 2 hours at 4oC, followed by a further 2 hours with pre-blocked Dynabeads M-280 Sheep anti-mouse IgG (Invitrogen 112-01D). Methylated DNA was purified using the MinElute PCR purification kit (Qiagen 28104), amplified using the NEBNext DNA library prep master mix set, and size-selected for 200-800bp fragments using AMPure XP beads (Beckman Coulter A63881). Indexed libraries were pooled and sequenced on an Illumina HiSeq2500, using a 50bp paired-end protocol Total RNA was extracted using the Allprep DNA/RNA Mini kit (Qiagen 80204) followed by Dnase treatment using the TURBO DNA-free kit (Life Technologies AM1907) mRNA was isolated from total DNA-free RNA (350ng) using the Dynabeads mRNA purification kit (Life Technologies 61006). Indexed, strand specific libraries were prepared using the Agilent SureSelect Strand specific Library Preparation kit (Agilent, G9691A) according to the manufacturer's instructions. Libraries were quantified/assessed using both the KAPA Library Quantification Kit (KAPA Biosystems KK4824) and Bioanalyzer 2100 system (Agilent). Indexed libraries were pooled and sequenced with a 100bp single-end protocol on an Illumina HiSeq2500 sequencer.

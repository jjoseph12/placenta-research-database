Methods Assay, extraction, and data processing text

Assay description

Four single nuclei sequencing collections from mouse placentas at E9.5, E10.5, E12.5, and E14.5, with an emphasis on the collection from the placental labyrinth.

Extraction protocol

Nuclei extractions using a modification of the Nuclei EZ kit protocol followed by FACS cleanup and collection using 10x Genomics Single Cell 3' v3 Library. Additional details included in the manuscript. 10x Genomics Single Cell 3' v3 Protocol

Main topic
This paper uses single nuclei RNA sequencing (snRNA-seq) to profile the murine placental development at four time points (E9.5, E10.5, E12.5, and E14.5), resolving all populations of the labyrinth at single-nucleus resolution and identifying distinct markers and transcript signatures for each population to understand placental development.

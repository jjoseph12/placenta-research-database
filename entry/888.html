Methods Assay, extraction, and data processing text

Assay description

We employed RNA-seq to analyze the global expression profiles of endometrial organoids (EORG-1, EORG-2, EORG-3, EORG-C; 3 replicates each). Next, we determined the global expression patterns upon estrogen treatment (3 replicates: EORG-E) and compared them to untreated controls (3 replicates: EORG-C).

Extraction protocol

RNA was extracted using the RNeasy kit (Qiagen) with the DNaseI (Qiagen) digest performed on the column according to manufacturer's protocol mRNA was isolated using the Dyabeads mRNA purification kit (Life Technologies 61006) and prepared into an indexed library using the ScriptSeq v2 RNA-Seq Library Preparation Kit (Epicentre SSV21106) according to the manufacturers' instructions. Indexed libraries were pooled and sequenced with a 100-bp single end protocol.

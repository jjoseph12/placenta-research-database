Assay description

First-trimester decidual tissues from ten HCMV-seronegative women and ten HCMV-seropositive women, each HCMV- or mock-infected and subjected to transcriptome analysis.

Extraction protocol

RNA was harvested using NucleoSpin RNA isolation kit (Macherey-Nagel). RNA libraries for 3' RNA sequencing were prepared using the CEL-seq2 protocol

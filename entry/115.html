Extraction protocol

For all ChIPs except EZH2, cells were crosslinked in 0.6% formaldehyde. For Ezh2 ChIPs, cells were crosslinked in 1.5mM EGS (ethylene glycol bis(succinimidyl succinate); ThermoFisher Pierce) in PBS for 30 minutes and then in 0.6% formaldehyde. Whole cell lysates were sonicated and chromatin extracts were immunoprecipitated using the specified antibody. Purified immunoprecipitated DNA was prepared for sequencing on the Illumina platform using Next Reagents (NEB). Total RNA was isolated using Trizol (Invitrogen). RNA-Seq libraries were prepared using Stranded mRNA-Seq Kits (Kapa Biosciences) and RNA HyperPrep Kits with RiboErase (Kapa Biosciences). TSCs and SM33 ESCs were fixed in 0.3% methanol-free formaldehyde for 30 min at 4 °C. Whole cell lysates were sonicated and RNA was immunoprecipitated using the specified antibody and isolated using Trizol (Invitrogen). Libraries were prepared using the Kapa Ribo-zero kit following the manufacturer’s instructions, pooled, and sequenced using single-end 75-bp reads on an Illumina Nextseq 500.

Main topic
This study investigates the relationships between long noncoding RNAs (lncRNAs) and Polycomb Repressive Complexes (PRCs) in mouse trophoblast stem cells, finding that genome architecture, lncRNA abundance, and CpG island DNA play important roles in PRC-induced chromatin modifications within lncRNA target domains.

Methods text

Assay description

RNA-seq analysis was performed using bTSC, differentiates TSC (day2, 3, 4, 5 and 6), Day7 IVF blastocyst (BL) and isolated trophectoderm (TE).

Extraction protocol

RNA was harvested using Rneasy micro kit (Qiagen). RNA libraries for RNA-seq were prepared using Smart-seq2 v4 Kit following manufacturer's protocols.

Main topic
This paper reports the establishment of bovine trophoblast stem cells (bTSCs) from blastocysts using a chemical cocktail (LCDM). The study demonstrates that bTSCs retain developmental potency and exhibit transcriptomic and epigenetic features characteristic of trophectoderm cells from early bovine embryos.

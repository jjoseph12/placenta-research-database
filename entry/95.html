Methods Assay, extraction, and data processing text

Assay description

RNA-seq was performed for the blastocystes homozygously or heterozygously deleted with the Region M on chromosome 19 and for the wild-type blastocysts. RNA-seq was also performed for the C57BL/6 mouse-derived ES and TS cells.

Extraction protocol

In vivo-developed blastocyst-stage embryos were collected at 88 h after hCG, then incubated in M2 medium microdrops. Each blastocysts was picked up from the microdrops, and RNA from each blastocyst was extracted using Allprep DNA/RNA Micro kit (QIAGEN). RNA libraries were prepared usig Ovation SoLo RNA-Seq Systems (NuGEN) for sequencing using standard Illumina protocols Total RNA was extracted using Allprep DNA/RNA Mini kit (QIAGEN). RNA-seq libraries were prepared using SureSelect strand-specific RNA library preparation kit (G9691A, Agilent). One microgram of total RNA was used as a starting material.

Methods Assay, extraction, and data processing text

Assay description

RNA-seq were applied on mESC, 2C::GFP+, 2C::GFP+/SGC, 2C::GFP+/SA cells, and TLSCs to profile their transcriptomes.

Extraction protocol

Total RNA was extracted from mESC, 2C::GFP+, 2C::GFP+/SGC and 2C::GFP+/SA cells using the Trizol kit (Thermo Fisher Scientific, catalog. no. 15596018) following the manufacturer’s instructions. PolyA(+) RNA was isolated for library construction. RNA libraries were prepared for sequencing using standard Illumina protocols

Methods Assay, extraction, and data processing text

Assay description

This GEO submission contains all DNA methylation and expression data produced for the study, including human lung cancer WGBS methylomes and RNA-seq as well as mouse 4T1 breast tumor methylomes.

Extraction protocol

The parental mouse mammary tumor cell line 4T1 (ATCC) and the derived clonal cell lines were cultured as described in \cite{wagenblast2015model}. Genomic DNA was extracted using the QIAmp DNA Blood Mini Kit (Qiagen). Bisulfite sequencing libraries were generated as previously described \cite{hodges2011primaryBloodMeth} In short, genomic DNA was fragmented using the Covaris LE220 sonicator to a target fragment size of 200bp. DNA fragments were repaired and ends blunted and phosphorylated. Then, adenylated fragments were ligated to Illumina-compatible paired-end adapters. Subsequently, DNA fragments were purified using the MinElute PCR Purification Kit (Qiagen). Fragments were then denatured and treated with sodium bisulfite using the EZ DNA Methylation-Gold Kit (Zymo Research). Then, the sample was desulfonated and PCR amplified with High Fidelity Expand Plus (Roche) using paired-end adapter-compatible primers. Illumnia sequencing was performed, generating 76-nucleotide paired-end reads. Illumina Truseq stranded RNA seq kit with Ribo minus depletion.

Main topic
This study introduces an improved method for identifying Partially Methylated Domains (PMDs) in methylomes, outlines a set of axioms for a functional definition of PMDs, and refines the criteria for determining whether a sample contains PMDs, thereby enabling low sequencing depth studies of PMD variation and elucidating the relationship between methylation loss, sequence, and replication timing.

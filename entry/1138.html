Methods Assay, extraction, and data processing text

Assay description

Mouse trophoblast stem cells were cultured using MEF conditioned media along with FGF4 and Heparin. Short hairpin RNA against Prkci mRNA was cloned in PLKO1 vector and a scrambled control was also used. Lentiviral supernatants were obtained from HEK 293T cells and were used to transduce TS cells described before. Transduced cells were selected using 1µg/ml puromycin. Knockdown efficiency was validated by real-time PCR analysis and western blotting. Whole cell-lysates were used to prepare RNA using Qiagen RNeasy Mini Kit with on column DNase digestion. RNA-seq analysis were performed using Illumina HiSeq2500 platform.

Extraction protocol

Total RNA from the whole cell-extract was isolated using RNeasy Mini Kit (#74104) from Qiagen per the manufacturer’s protocol with on column DNase digestion. RNA concentrations were quantified using a NanoDrop Spectrophotometer at a wavelength of 260nm. Integrity of the total RNA samples was evaluated using an Agilent 2100 Bioanalyzer (Agilent Technologies Inc., Santa Clara, CA) and the samples with RNA integrity values above 9.0 were used for the sequencing experiments. Total RNA was used to construct RNA-seq libraries using the Illumina TruSeq Stranded Total RNA Sample Preparation Kit according to manufacturer's instructions.

Main topic
This paper investigates the role of atypical protein kinase C iota (PKCλ/ι) in establishing the maternal-fetal exchange interface during in utero mammalian development, demonstrating its essential role in trophoblast progenitor differentiation and placentation using human trophoblast stem cells and genetic mouse models.

Methods Assay, extraction, and data processing text

Assay description

Examination of 1149 3D Rosette-to-Lumen embryoid cells, 317 2D 2i/LIF Embryonic stem cells (2D 2i/LIF ESCs), 283 2D induced trophoblast stem cells (2D iTSCs) and 182 2D induced extraembryonic endoderm stem cells (2D iXEN)

Extraction protocol

Rosette-to-Lumen stage embryoids and 2D mono-culturestem cells were harvested by washing with PBS and incubation in StemPro Accutase Cell Dissociation Reagent to create a single-cell solution Cells lysed in Guanidine Hydrochloride (50 mM), dNTPs (17.4mM), 2.2µM SMART dT30VN primer lysis buffer Nextera XT DNA Library Preparation Kit (Illumina) NextSeq500 system SR 75bp with 2*8bp index reads

Main topic
This paper presents a simple system for generating embryo-like structures from embryonic stem cells (ESCs) through transcription factor-mediated reprogramming in a 3D co-culture, resembling peri-implantation mouse embryos and allowing the study of early embryogenesis.

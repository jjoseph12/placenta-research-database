Methods text

Assay description

ARDS was induced via an intra-tracheal injection of lipopolysaccharide (LPS)at the dose of 5mg/kg in phosphate buffered saline (PBS). After 4h following LPS injection, mice were randomized to receive a single intravenous injection of 1x10^6 MSCs (of a single source) or PBS. After 48 hours, whole lung tissue was collected and homogenized in trizol (Thermofisher Scientific, USA). RNA extraction was then done using RNA mini kit (Qiagen, Germany) according to the manufacturer’s guidelines with the quality of RNA evaluated using an Agilent bioanlyzer 2100 system. Samples with RNA integrity number (RIN) ≥ 6.8 were considered for library preparation.

Extraction protocol

total RNA was extracted from each replicate using the RNAeasy minikit (qiagen) RNA libraries were prepared for sequencing using standard Illumina protocols

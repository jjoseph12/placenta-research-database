Methods Assay, extraction, and data processing text

Assay description

HFFs reprogrammed into hiTSC lines by transient ectopic expression of GATA3, OCT4, KLF4, MYC (GOKM) were subjected to RNA-seq, along with samples of HFFs, hbdTSCs, hESCs and hiPSCs

Extraction protocol

Total RNA was isolated using the Macherey-Nagel RNA NucleoSpin kit (Ornat) mRNA libraries were prepared using the SENSE mRNA-seq library prep kit V2 (Lexogen)

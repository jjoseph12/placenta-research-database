Methods Assay, extraction, and data processing text

Assay description

PD-TOrgs were established from 3 independent placental tissues using a modified version of previously described protocols and differentiated into EVT-trophoblast organoids by removal of WNT signaling components. Live trophoblasts were purified for mRNA sequencing from n=3 pooled regenerative organoid cultures on culture day 0 and from n=3 pooled EVT-differentiated organoid cultureds on culture day 7 in EVT-differentiation media using the 10X Genomics chromium single cell 3’ reagent v3 chemistry kit.

Extraction protocol

RNA from all samples was prepared using TriZol reagent followed by Rneasy Mini Kit purification, following manufacturer protocol. RNA purity was confirmed by NanoDrop Spectrophotometry and integrity confirmed by Agilent BioAnalyzer. Only RNA with a RIN > 8.0 was used for sequencing. Libraries were constructed using the 10X Genomics chromium single cell 3’ reagent v2 chemistry kit for all placental tissue samples and using the chromium single cell 3’ reagent v3 chemistry kit for all trophoblast organoid samples at a read depth of 50,000 reads/cell for undifferentiated and a read depth of 150,000 reads/cell for EVT-differentiated PD-TOrg samples.

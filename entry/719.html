Methods Assay, extraction, and data processing text

Assay description

RNA-seq for maternal blood

Extraction protocol

Buffy coat was homogenized using the QIAshredder (Qiagen 79654) before extraction with the Allprep Universal Kit for DNA/RNA/miRNA Extraction (Qiagen 80224) RNA quality was determined on a fragment analyzer instrument and quantity measured by qubit. 500ng of high quality RNA was used as input into the Kapa RNA HyperPrep with RiboErase plus globin kit. 12 PCR cycles were used for final library amplification. All samples were pooled and sequenced on a NextSeq500 instrument to generate 25M, 75bp single-end reads per sample. Basecalling was performed on instrument using RTA v2.4.11 and converted to fastqs using bcl2fastq v2.20.0.422

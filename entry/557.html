Methods Assay, extraction, and data processing text

Assay description

Gestation day 21 female rat liver and placenta mRNA and microRNA RNAseq profiles following exposure to ketoconazole from gestation days 6 - 20.

Extraction protocol

Total RNA was extracted from organs stored in RNAlater using a mirVana RNA isolation kit (catalog number AM1560; ThermoFisher Scientific) according to the manufacturer’s instructions. RNA quantity was measured using a NanoDrop ND-1000 spectrophotometer. Total RNA quality was examined using an Agilent Bioanalzyer (Agilent Technologies). miRNA was purified from the same tissue homogenate as the Total RNA, using mirvana (catalog number AM1560; ThermoFisher Scientific, Waltham, MA) and quanitified using the Bioanalyzer (Agilent Technologies, Santa Clara, CA). ). A sequencing library was prepared from 1ug total RNA using the Illumina TruSeq Stranded mRNA Library Prep Kit and protocol (Illumina, San Diego, CA). Briefly, mRNAs were fragmented using ZnCl2 solution, reverse transcribed into cDNA using random primers, end repaired to create blunt end fragments, 3’ A-tailed, and ligated with Illumina paired-end library adaptors. Ligated cDNA fragments were PCR amplified using Illumina paired-end library primers and purified PCR products were checked for quality and quantity on the Agilent TapeStation (Agilent, Santa Clara, CA). Average library insert size was 300bp, and final sequencing concentration was determined by quantitation on the Agilent TapeStation (Agilent, Santa Clara, CA). For the microRNA libraries, sequencing libraries from each small RNA sample were prepared using 1 µg input with the TruSeq small RNA kit according to manufacturer’s instructions (Illumina, Inc., San Diego, CA). Briefly, Illumina TruSeq adapters are ligated onto purified smRNA ends, reverse transcribed, and the cDNA are PCR-amplified using Illumina indexed TruSeq primers. PCR-amplified libraries were checked for quality and quantified using the Agilent Tapestation 4200 with D1000 screentape. Equal amounts of library were pooled based on nano-molarity concentration and then size-selected using a PippinHT automated DNA size selector (Sage Science Inc., Beverly, MA). The size-selected samples were ethanol precipitated to concentrate and then checked for quality and quantity using an Agilent TapeStation 4200 with D1000 screentape.

Main topic
This study investigates the potential of using molecular-level changes (maternal epigenomic and transcriptomic data) to derive a point of departure (POD) for risk assessment in developmental toxicity testing, using the rat ketoconazole model.

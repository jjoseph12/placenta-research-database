Extraction protocol

Genomic DNA was extracted using QIAamp DNA Mini Kit (QIAGEN GmbH, Germany). Library was constructed using modified Illumina RRBS Sample Preparation Protocol. Total RNA was extracted using TRIZOL protocol (Life Technologies). Sequencing library was constructed using Illumina mRNA-Seq Sample Preparation protocol.

Main topic
This study investigates DNA methylation changes associated with Down syndrome (DS) in placenta villi tissues, revealing global DNA hypermethylation in DS samples and identifying genes with perturbed DNA methylation in promoters that are functionally relevant to DS phenotypes.

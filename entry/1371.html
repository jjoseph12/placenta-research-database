Methods text

Assay description

Bisulfite converted DNA from 4 buccal, 4 blood and 4 chorionic villus samples was hybridized to the Illumina Infinium HumanMethylation450 BeadChip array.

Extraction protocol

Genomic DNA was purified using the Dneasy Blood and Tissue kit followed by bisufite conversion using the ES DNA methylation kit following manufacturer's protocols.

Main topic
This paper focuses on enhancing probe annotation of the Illumina Infinium HumanMethylation450 BeadChip array to facilitate biologically significant data interpretation, by adding or expanding on annotations such as SNPs in the probe target, probe binding specificity, CpG classification of target sites, and gene feature classification of target sites.

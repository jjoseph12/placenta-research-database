Assay description

Main topic
This paper presents a collation of microarray data relevant to genomic imprinting into a Web Atlas of Murine genomic Imprinting and Differential EXpression (WAMIDEX). The atlas aims to be a useful tool for studying genomic imprinting using mouse models with genetic material originating from only one parent or gene mutations leading to epigenetic deficiencies.

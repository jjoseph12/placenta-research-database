Extraction protocol

Total RNA from TGCs was isolated using TRIzol (#15596026, Thermo Fisher Scientific). rRNA was depleted using NEBNext rRNA Depletion Kit (Human/Mouse/Rat) (NEB # E6310L). cDNA synthesis was performed using NEBNext Ultra II Directional RNA Library Prep Kit (NEB #E7760S) and NEBNext Multiplex Oligos for Illumina (Index Primer Set 1) (NEB # E7335S). Sequencing was performed using an Illumina NextSeq 500 with 75bp single read runs. Chromium Next GEM Single Cell 3' Reagent Kits v3.1 was used for making cDNA library using 10X Genomic reagents.

Main topic
This paper investigates polyploidy in murine placental cell types, identifying factors that license polyploidy using single-cell RNA sequencing and demonstrating the role of Myc in supporting replication, nucleotide biosynthesis genes, and rRNA production in placental giant cells.

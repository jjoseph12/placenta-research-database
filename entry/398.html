Methods Assay, extraction, and data processing text

Assay description

Human Plancental villi from normal and miscarriage sample (below 8 weeks) was isolated. Whole placental villi were used to prepare RNA using Qiagen RNeasy Mini Kit with on column DNase digestion. RNA-seq analysis were performed using a illumina HiSeq2000 platform.

Extraction protocol

Total RNA from the whole placental viili was isolated using RNeasy Mini Kit (#74104) from Qiagen per the manufacturer’s protocol with on column DNase digestion. RNA concentrations were quantified using a NanoDrop Spectrophotometer at a wavelength of 260nm. Integrity of the total RNA samples was evaluated using an Agilent 2100 Bioanalyzer (Agilent Technologies Inc., Santa Clara, CA). Sequencing libraries were prepared using the NuGEN Universal Plus Stranded (fr-secondstrand) mRNA Sample Preparation Kit

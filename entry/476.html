Methods text

Assay description

Array profiling was performed using the Mouse Gene 1.0 ST Array (Affymetrix) and the analysis of the data was performed using GeneSpring GX 12.1 (Agilent, Santa Clara, CA, USA), with two algorithms: RMA (Robust Multiarray Average) and PLIER (Probe Logarithmic Intensity Error). Log2 RMA values are included in this submission. PLIER values are not included.

Main topic
This paper investigates how the placenta adapts to fetal signals, demonstrating that endothelial and fetus-derived IGF2 is required for the continuous expansion of the feto-placental microvasculature in late pregnancy, mediated through IGF2R and angiopoietin-Tie2/TEK signaling.

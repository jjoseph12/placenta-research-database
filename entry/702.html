Methods text

Assay description

Gene expression analysis of RNA-seq data for mouse placental tissues on embryonic day (e) e7.5, e8.5 and e9.5.

Extraction protocol

Placenta tissue was collected from timed pregnant mice following the guidelines and protocol approved by Iowa State University Institutional Animal Care and Use Committee (IACUC), protocol number 18–350. Placenta samples were collected at e7.5, e8.5, e9.5 following the same protocol in Tuteja et al., 2016. Placenta tissue was collected for a total of 6 biological replicates for each timepoint. For e7.5, 12 ectoplacental cones (EPCs) were collected per replicate. For e8.5, five placentas were collected per replicate, and for e9.5, one placenta was collected per replicate. Tissues were processed immediately after collection for RNA isolation using the Purelink RNA micro scale kit (Thermofisher, 12183016). RNA concentration and RIN values were measured using The RNA 6000 Nano assay kit on the Agilent 2100 Bioanalyzer (GTF facility, ISU), and all samples had a RIN score ≥ 7.7 Libraries were sequenced using the Illumina HiSeq 3000 with single-end 50 base pair reads. The pooled library sample was run over two sequencing lanes (technical replicates for each sample).

Methods text

Assay description

RNA sequencing analysis of endothelial cells the E5.5 decidua, bEnd5 endothelial cells, E4.5 mural trophectoderm, E4.75 mural trophectoderm and trophoblast giant cells (TGCs).

Extraction protocol

Cell lysate of the endometrial tissue was labelled for CD31 and CD45 and FACS sorted for CD31+ and CD45- cells. RNA was isolated from the FACS sorted cells using RNeasy Mini Kit (Qiagen). 10ng of RNA was used to prepare library using NEB Next Single Cell/Low Input cDNA Synthesis and Amplification Module (NEB). The cells were trypsinised and RNA was isolated using RNeasy Mini Kit (Qiagen). 10ng of RNA was used to prepare library using NEB Next Single Cell/Low Input cDNA Synthesis and Amplification Module (NEB). Laser dissected samples were directly lysed in the lysis buffer provided by the NEB Next Single Cell/Low Input cDNA Synthesis and Amplification Module (NEB). 3ul of the lysate was used to prepare library using NEB Next Single Cell/Low Input cDNA Synthesis and Amplification Module (NEB). Lysis buffer from NEB Next Single Cell/Low Input cDNA Synthesis and Amplification Module (NEB) was directly added to the wells and the samples were frozen to lyse the cells. 3ul of the lysate was used to prepare library using NEB Next Single Cell/Low Input cDNA Synthesis and Amplification Module (NEB).

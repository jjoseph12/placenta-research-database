Assay description

We sequenced mRNA from primary human endometrial stromal fibroblasts and in vitro human decidualized stromal fibroblasts.

Extraction protocol

RNA was extracted using Qiagen Rneasy Mini Kit followed by on-column treatment with DNase-1 treatment RNA libraries were prepared for sequencing using standard illumina protocols.

Main topic
This study investigates the cell-cell interactome of fetal placental trophoblast cells and maternal endometrial stromal cells using single-cell transcriptomics, revealing a highly cell-type-specific expression of G-protein-coupled receptors and identifying uterine decidual cells as a cell-cell interaction hub.

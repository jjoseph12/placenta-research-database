Assay description

Examination of gene expression by unstimluated versus IFN-γ-stimulated endothelial cells or pericytes

Extraction protocol

Total RNA was extracted using the TRIZOL-chloroform extraction method. RNA was cleaned using the QIAGEN Rneasy Cleanup kit. Poly-A, strand-specific RNA library construction was performed by the Yale Center for Genomic Analysis utilizing the TruSeq Library Prep Kit 2.0 per the manufacturers specifications. . Following first-strand synthesis with random primers, second strand synthesis was performed with dUTP for generating strand-specific sequencing libraries.

Main topic
Early acute rejection of human allografts is mediated by circulating alloreactive host effector memory T cells (TEM). IFN-γ-activated pericytes negatively regulate proliferation of allogeneic effector memory T cells through induction of indoleamine 2,3-dioxygenase 1.

Workbook field Main topic of the publication
Reviewed answer The publication investigates the immunomodulatory effects of human placental microvascular pericytes (PCs) on allogeneic T cells, showing that IFN-γ-stimulated PCs suppress T cell proliferation via IDO1-mediated tryptophan depletion.
Source excerpt
We report that unstimulated PCs, like ECs, can directly present alloantigen to T EM, but while IFN-γ–activated ECs (γ-ECs) show increased ability to stimulate alloreactive T cells, IFN-γ–activated PCs (γ-PCs) instead suppress T EM proliferation but not cytokine production or signaling.

Extraction protocol

Total RNA was purified from term placentas using a combination of TRIzol and Qiagen columns. RNA-seq libraries were prepared using the SureSelect Strand-Specific RNA Library Prep for Illumina Multiplexed Sequencing kit (Agilent). For capture-sequencing, pre-amplified RNA-seq libraries were enriched for THE1B containing transcripts using a custom panel of 120 nt THE1B RNA oligos and the SureSelectXT RNA Target Enrichment kit (Agilent). Libraries were sequenced as 75 bp paired-end reads on an Illumina HiSeq machine. Lysates were clarified from sonicated nuclei and histone-DNA complexes were isolated with antibody using the MAGnify ChIP kit (Thermo Fisher) Libraries were prepared using the DNA Smart ChIP-seq library kit (Takara).

Main topic
This paper investigates the role of the endogenous retroviral long terminal repeat transposon-like human element 1B (THE1B) in selectively controlling placental expression of corticotropin-releasing hormone (CRH) in humans and other anthropoid primates, which is crucial for regulating gestational length.

Methods Assay, extraction, and data processing text

Assay description

Total RNA was isolated using Trizol method and cDNA was prepatred using TruSeq Stranded Total RNA LT kit (RS-122-2302) for Illumina sequencing.

Extraction protocol

Total RNA was isolated using TRIzol (#15596026, Thermo Fisher Scientific) from placentas at 14.5 dpc. cDNA libraries for four individual placentas from each genotype were prepared after ribo-depletion using the Truseq stranded total RNA library prep kit with ribo-zero gold (#RS-122-2302, Illumina).

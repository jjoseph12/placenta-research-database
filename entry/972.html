Methods Assay, extraction, and data processing text

Assay description

Comparison of gene expression patterns in Extraembryonic Ectoderm and cancer

Extraction protocol

RNA was isolated using the RNAeasy Micro Kit from Qiagen RNA-seq libraries generated using the SMRT-seq v4 Ultralow Input Kit (Clontech) according to the manufacturer’s protocol using 10-11 LD PCR cycles. Libraries were generated from 150 pg of cDNA using the Nextera XT DNA library preparation kit (Illumina) using 12 PCR cycles.

Main topic
This paper compares the epigenetic landscapes that evolve during early mammalian development by generating whole genome bisulfite sequencing (WGBS) and RNA-seq datasets from mouse precompacted embryos, Inner Cell Mass (ICM) and Trophectoderm from blastocysts, as well as Epiblast and Extraembryonic Ectoderm (E×E) from conceptuses, to understand genome regulation in human cancers.

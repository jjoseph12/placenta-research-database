Methods Assay, extraction, and data processing text

Assay description

We performed RNAseq to analyze the global expression profile of two different trophoblastic subtypes.

Extraction protocol

RNA was extracted using AllPrep DNA/RNA/miRNA Universal Kit (Qiagen). Total RNA was depleted from ribosomal RNA using the NEBNext rRNA Depletion Kit (NEB). Libraries were prepared from rRNA-depleted total RNA using the NEBNext Ultra Directional RNA Library Prep Kit with the NEBNext High-Fidelity 2X PCR Master Mix (both from NEB). The libraries were sequenced on a NextSeq 500 sequencer (Illumina) with an average of 10 million reads per library using paired-end sequencing (2x150 bp)

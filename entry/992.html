Methods Assay, extraction, and data processing text

Assay description

Examination of impact of diet-induced obesity on gene expression in the early post-implantation mouse embryo.

Extraction protocol

RNA was extracted using Acturus Picopure RNA extraction kit with minor modifications. Second elutions of RNA from each embryo were used to sex embryos. RNA quality was assessed using Agilent BioAnalyzer Pico kit. Only samples in which RNA integrity was ensured (RIN>7) were used for further processing. Libraries were prepared according to ClonTech's instructions accompanying the Low-Input Strand-Specific Total RNA-Seq for Illumina RNA-Seq (Cat.# 634861). Briefly, rRNA depletion was performed using ClonTech RiboGone Mammalian kit. First RNA is fragmented and converted to single-stranded (ss) cDNA that contains sequences complementary to the SMARTer Stranded Oligo. The purified first-strand cDNA is amplified into RNA-seq libraries using SeqAmp DNA Polymerase, the Universal Forward PCR Primer, and the Reverse PCR Primers from the Illumina Indexing Primer Set. Library quality was assessed using the Agilent 2100 Bioanalyzer and the High Sensitivity DNA Chip from Agilent’s High Sensitivity DNA Kit (Cat. No. 5067-4626). Individual and pooled library concentrations was assessed using KAPA Library Quantification Kit-Illumina® Platforms.

Methods Assay, extraction, and data processing text

Assay description

To investigate the mechanisms underlying preeclampsia (PE) we used iPSC derived from the placentas of three PE patients (1932, 1933, 1981) and three control patients (1754, 1938, 1947), converted these primed iPSC to naive iPSC and then differentiated the primed and naive iPSC lines to trophoblast stem cells (TSC) and extravillous trophoblast (EVT). We then performed gene expression profiling on all of these samples using RNA-seq. For each timepoint and patient, we sequenced 3 replicates.

Extraction protocol

Total RNA was isolated using mirVana RNA Isolation Kit (Ambion). RNA concentration was measured using Qubit RNA BR assay kit (ThermoFisher). RNA integrity was checked using RNA 6000 Nano chip read by a 2100 bioanalyzer (Agilent). All samples had a RIN above 8.0. Total RNA was isolated using mirVana RNA Isolation Kit (Ambion).

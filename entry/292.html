Assay description

Single Cell RNA-sequencing data collected from both the Placental Villi/Basal Plate and Smooth Chorion regions from four human placental samples (8 total samples).

Extraction protocol

Cell isolation protocols described in Marsh et al., 2022 - PV/BP isolation described in Fisher et al., 1989; Kliman and Feinberg, 1990; SC isolation described in Garrido-Gomez et al., 2017 10x Genomics Single Cell 3' v3 Protocol

Main topic
This study uses single-cell RNA sequencing to compare cell types and molecular programs between the villous chorion and smooth chorion regions in the second trimester human placenta, identifying a smooth chorion-specific cytotrophoblast population that regulates barrier function and extravillous trophoblast invasion.

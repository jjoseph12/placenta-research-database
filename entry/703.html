Methods Assay, extraction, and data processing text

Assay description

Compare gene expression in ferroportin knockout (KO) and the control (C) placentas.

Extraction protocol

RNA was extracted from placenta using Rneasy plus mini kit (Qiagen, cat. no. 73404). NEBNext Ultra RNA Library Prep Kit for Illumina (cat. no. E7770) was used for the construction of sequencing libraries following manufacturer’s instructions.

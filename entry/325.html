Assay description

Extraction protocol

Placentas were removed, pulverized in liquid nitrogen. Total RNA was isolated using Trizol reagent (Life techologies) and puriﬁed with GeneJET RNA purification kit (Thermo) and RNase-free DNase set (QIAGEN) following manufacturer’s instructions.RNA electrophoresis was conducted to inspect RNA integration. RNA libraries were prepared for sequencing using standard Illumina protocols

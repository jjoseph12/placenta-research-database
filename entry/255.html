Methods text

Assay description

RNA-seq analysis on placental CD45+ cells isolated from Ctrl, WT(STZ) and Nlrp3(STZ) E17 embryos.

Extraction protocol

Placenta were homogenised. CD45+ cells were sorted by flow cytometry and collected for RNA isolation. The cDNA synthesis and amplification were done as recommended by Clontech. cDNA libraries were prepared using Nextera XT DNA Sample preparation reagents. Fragmented and tagged libraries were quantified using an agilent bio-analyzer, pooled and sequenced on a HiSeq 6000 platform (Illumina) using the pair-end 75-bp sequencing strategy.

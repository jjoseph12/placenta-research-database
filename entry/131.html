Methods text

Assay description

3'mRNA from the hiPSCs was sequenced on a NextSeq500 in 75bp single-end reads.

Extraction protocol

RNA was extracted using the PureLink RNA Minit Kit (Thermo Fisher). 3'mRNA hiPSC libraries were prepared using the Quant-seq 3’ mRNA Library Prep Kit FWD (Lexogen). For the hiPSCs, 75bp single-end reads were sequenced on the NextSeq500.

Main topic
This paper investigates the impact of monosomy X on an in vitro model for early human placenta using X-monosomic human induced pluripotent stem cells (hiPSCs), revealing impaired secretion of placental growth factor and chorionic gonadotropin in X-monosomic trophoblast-like cells.

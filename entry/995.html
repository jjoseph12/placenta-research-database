Methods text

Assay description

TS-like cells were generated from ES cells using CAG factors, followed by deep sequencing, using Illumina

Extraction protocol

For RNA-seq, total RNAs were extracted using Rneasy plus mini kit (Qiagen). RNA- and ChIP-sequencing libraries were generated using library prep kits (NEB) according to the manufacturer’s instructions. ATAC-seq samples were performed as previously described (Buenrostro et al., 2015)

Main topic
This paper investigates the mechanisms of transcription factor-mediated direct reprogramming of mouse embryonic stem cells to trophoblast stem-like cells, focusing on how these factors mediate the repression of initial cell-type-specific genes while activating target cell-type-specific genes.

Assay description

Examination of global transcriptional profiles in control and mutant placenta labyrinth at 2 developmental stages (E12.5 and 13.5).

Extraction protocol

Bead homogonization in trizol, Direct-zolTM RNA MiniPrep Plus Kit (Zymo Research) for extraction of RNA mRNA was enriched by pull-down using the NEBNext Poly(A) mRNA magnetic isolation module (New England Biolabs). Libraries were prepared using the NEBNext Ultra Directional RNA Library Prep Kit (New England Biolabs), skipped actinomyosin, libraries not stranded

Methods Assay, extraction, and data processing text

Assay description

Defining allele-specific genome features from the mouse in 23 tissues and developmental stages

Extraction protocol

Total RNA and DNA were extracted using TRI-reagent (Sigma-Aldrich T9424) according to the manufacturers protocol. Total RNA was DNaseI treated using the DNA-FreeTM kit (Ambion). RNA-seq: DNaseI treated (DNA-FreeTM Ambion) total RNA (1-3 µg) was depleted for Ribosomal RNA using the RiboZero rRNA removal kit (Human/Mouse/Rat) (Epicentre) or enriched for polyA containing mRNA (Illumina). Strand-specific RNA-seq libraries were prepared employing the TruSeq RNA Sample Prep Kit v2 (Illumina) modified as described in Sultan et al. 2012 for strand-specific sequencing. ChIP-seq: Native ChIP was conducted as described in Regha et al. 2007. ChIP-seq libraries were prepared using the TruSeq ChIP Sample Prep Kit (Illumina).

Main topic
This paper analyzes RNA-seq data from 23 F1 mouse tissues from different developmental stages to determine the dynamics of allelic-specific expression, revealing that allelic expression arising from genetic or epigenetic differences is highly tissue-specific and regulated by tissue-specific enhancers.

Extraction protocol

Cells were dissociated using TrypLE, clumps removed using cell strainers and pelleted. Transfected (mCherry positive) and untransfected (mCherry negative) resuspended cells were isolated by fluorescent activated cell sorting (FACS). Cells were pelleted, washed in PBS and resuspended in lysis buffer (10mM Tris-HCl pH 7.4, 10mM NaCl, 3mM MgCl2, 0.1% IGEPAL). After a 10min centrifugation at 4 C, nucleic extracts were resuspended in transposition buffer for 1 hour at 37 C and purified using a QIAGEN PCR Purification kit following manufacturer’s instructions. Eluted transposed DNA was amplified by PCR with Nextera primers to generate single-indexed libraries. A maximum of 12 cycles of PCR was used to prevent saturation biases Approximately 1x10^8 adherent cells were fixed in 4% PFA for 9 min at room temperature, washed in PBS + protease inhibitors and detached using cell scrapers. Processing was performed using a modified Xenopus protocol (Methods Mol Biol. 2017;1507:23-42). Nuclei were isolated in cell lysis buffer (10mM Tris-HCl pH8, 10mM NaCl, 0.2% IGEPAL CA-630) and pelleted. To sheer chromatin, pellets were resuspended in CEWB1 buffer (10mM Tris-HCl pH8, 150mM NaCl, 1mM EDTA, 0.1% SDS, 0.25% sodium deoxycholate, 1% IGEPAL CA-630) and sonicated using a covaris S220 Focused-ultrasonicator: duty cycle = 5%, intensity = 4, cycles/burst = 200, procedure time = 420 seconds, temperature = <8°C. Reverse cross-linking of ChIP and input samples were performed as described previously (Methods Mol Biol. 2017;1507:23-42), purified using QIAquick PCR purification kit and concentrations determined using the QubitTM dsDNA HS Assay. Paired-end library prep was according to the Gentsch and Smith, 2017 (Methods Mol Biol. 2017;1507:23-42). Libraries were sequenced as paired-end, 101bp reads on the Illumina High-Seq 2500 platform (Francis Crick Institute). Cells were harvested in TRIzol and snap frozen. RNA was extracted using the RNAeasy Plus Micro Kit according to manufacturer instructions. RNA integrity (RIN) was determined using Caliper LabChip GX (Perkin Elmer, USA). Libraries were generated using the TruSeq Stranded mRNA Library Prep Kit as per manufacturer’s instructions (Illumina, USA) and sequenced as 76bp single-end, stand-specific reads on the Illumina HiSeq 4000 platform (Francis Crick Institute).

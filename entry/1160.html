Methods Assay, extraction, and data processing text

Assay description

Comparative gene expression profiling analysis by RNA-seq analsysis and DNA methylation profiling by meDIP-seq data for Padi2/3 DKO cells and WT trophoblast stem cells.

Extraction protocol

RNA was harvested using Trizol reagant and DNA was harvested using standard SDS lysis buffer RNA libraries for RNA-seq were prepared using Ultra II Directional RNA Library Prep kit. meDIP libraries were prepared using NEB ultra II DNA Library Prep kit.

Main topic
This study investigates the roles of protein arginine deiminases (PADIs) in mouse trophoblast stem cells (TSCs), showing that PADI function supports the pluripotent state of embryonic stem cells and promotes cellular differentiation.

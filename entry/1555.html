Methods Assay, extraction, and data processing text

Assay description

Examine Eset-binding sites and compare the H3K9me3 state between Eset knockdown mouse ES cells and control knockdown mouse ES cells.

Extraction protocol

Whole cell extracts were sonicated to solubilize the chromatin. The chromatin extracts containing DNA fragments with an average size of 500 bp were immunoprecipitated using different antibodies. ChIP-enriched DNA from multiple ChIP experiments was pooled and quantified using PicoGreen dsDNA quantitation kit (Invitrogen). The ChIP-enriched DNA was processed for Solexa sequencing using ChIP-Seq Sample Prep Kit (Illumina).

Main topic
The histone H3 Lys 9 (H3K9) methyltransferase Eset is an epigenetic regulator critical for the development of the inner cell mass (ICM). This paper investigates the role of Eset in restricting extraembryonic trophoblast lineage potential in embryonic stem cells.

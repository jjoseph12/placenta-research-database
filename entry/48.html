Methods text

Assay description

RNA was extracted from placenta tissue at term using a combination of TRI reagent and cleanup with Qiagen Rneasy columns.

Extraction protocol

RNA was extracted from placenta tissue from individual subjects using TRi regaents and cleanup was done using the RNeasy Mini Kit per manufacturer’s instructions including on-column DNase digestion. Total RNA was quantified using a sphectrophometrically. Directional cDNA libraries for mRNA-sequencing were prepared using polyA-mRNA from individual RNA samples using Illumina TruSeq reagents. Briefly, 1 μg of total RNA was utilized for mRNA isolation using poly-A magnetic beads and was fragmented prior to first and second strand cDNA synthesis. Libraries were generated via PCR including dual-indexed barcodes. Following purification with AmpureXP beads libraries were quantitated using Qubit dsDNA reagents. Pooled cDNA libraries were sequenced (150 bp paired reads) using a NovaSeq 6000 instrument.

Main topic
This study examines the interactions between maternal malnutrition and heat stress during pregnancy on fetal growth in a resource-limited setting in Pakistan, utilizing data from the Women First Preconception Nutrition trial to analyze the impact of ambient temperature on neonatal anthropometry at birth.

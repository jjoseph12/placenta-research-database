Methods Assay, extraction, and data processing text

Assay description

RNA-seq and ChIP-seq from F1 extraembryonic tissues extracted from reciprocal crosses between RSDEL mouse and CAST/EiJ

Extraction protocol

RNA was extracted from TRIzol using standard protocols. The Illumina TruSeq kit was used to create polyA+ libraries from total RNA. We generated strand-specific libraries for tissues collected form the F1 crosses. All the libraries were run on a Bioanalyzer to assess fragment size, and concentration and sequenced on a HiSeq 2000

Main topic
This paper examines the mechanism of action of the imprinted long non-coding RNA Airn in silencing distant genes on the same chromosome, focusing on the enhancer interference hypothesis and the role of chromosome interactions in this process.

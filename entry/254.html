Extraction protocol

Isolated nuclei were prepared from 50,000 sorted LSK cells puriifed by flow cytometry. the transposase reaction was performed for 60 min at 37°C. mix. The transposed DNA was purified using a Qiagen MinElute kit and amplified using 1XNEBnext PCR master. The libraries were purified with SPRI beads double size selection (0.4/1.2X) and then sequenced on the Illumina NovaSeq X Plus with PE150, aiming >120M read pairs per sample. LSK cells were isolated by FACS, and DNA was extracted using the QIAamp DNA Mini Kit (Qiagen) as per the manufacturer’s instructions. Genomic DNA was bisulfite-converted with the EZ DNA Methylation Kit (Zymo Research, Irvine, USA). Libraries were sequenced on the Illumina Novaseq6000 with 100 bp paired end reads Placenta were homogenised. CD45+ cells were sorted by flow cytometry and collected for RNA isolation. The cDNA synthesis and amplification were done as recommended by Clontech. cDNA libraries were prepared using Nextera XT DNA Sample preparation reagents. Fragmented and tagged libraries were quantified using an agilent bio-analyzer, pooled and sequenced on a HiSeq 6000 platform (Illumina) using the pair-end 75-bp sequencing strategy.

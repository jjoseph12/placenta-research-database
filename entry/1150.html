Extraction protocol

Total RNA was isolated using mirVana RNA Isolation Kit (Ambion). RNA concentration was measured using Qubit RNA BR assay kit (ThermoFisher). RNA integrity was checked using RNA 6000 Nano chip read by Aligent 2100 bioanalyzer. All samples had a RIN above 8.0. RNAseq libraries were prepared using the TruSeq Stranded Total RNA Sample preparation kit with Ribo-Zero Gold (Illumina)

Main topic
This paper models preeclampsia (PE) using human induced pluripotent stem cells (iPSC) derived from placentas of pregnancies with and without PE, finding that PE-iPSC-derived trophoblast showed a defect in syncytialization and a blunted response to hypoxia, recapitulating multiple defects associated with placental dysfunction.

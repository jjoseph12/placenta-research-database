Methods Assay, extraction, and data processing text

Assay description

ChIP-seq using WT and KO ESCs/TSCs for ZFP568 and H3K9me3. RNA-seq using WT and KO ESCs/TSCs and hybrid ESCs. ChIP-seq using IGF2 promoter crispr cell lines for ZFP568 and H3K9me3. Two platforms, Illumina Hiseq2500 and Solid 5500xL were used for sequencing. For Solid platforms, raw data was aligned to mm9 by LifeScope™ Genomic Analysis Software v2.5.1 to generate bam files. All data from Illumina platform was deposited in fastq format.

Extraction protocol

RNA was prepared from cells or embryos using the RNeasy Plus Mini or Micro kit (Qiagen) with on-column DNase digestion. RNA-seq libraries were constructed according to Illumima protocol and sequenced with the Illumina Hiseq 2000. ChIP-seq libraries were constructied by using DNA SMART™ ChIPSeq Kit from Clontech

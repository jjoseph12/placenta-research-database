Methods Assay, extraction, and data processing text

Assay description

RNA sequencing on placenta-derived MSCs before and after exposure to 1mM aspirin to find differentially expressed genes.

Extraction protocol

Total RNA was extracted from the cells according to manufacturer’s protocols with the RNeasy Mini Kit (Qiagen). Libraries were prepared using the NEB Ultra II Library Preparation Kit and NEBNext® Multiplex Oligos for Illumina (Dual Index Primers Set 1) (New England BioLabs) following the manufacturer’s protocol.

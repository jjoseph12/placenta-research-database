Methods Assay, extraction, and data processing text

Assay description

We obtained human peri-implantation embryos through blastocyst to early post -implantation stages using an in vitro coculture system, and profiled transcriptome of individual trophoblast cells collected from these embryos. By systematic analysis methods, we revealed the genetic networks regulating peri-implantation trophoblast development.

Extraction protocol

Embryos were treated with trypsin to detach from dishes. Embryos then be and manually transferred to a new dish containing trypsin for further dissociation for 3 to 5 minutes with repeated aspiration using a mouth-controlled, finely drawn capillary pipette. Single cell was then manually picked using the capillary pipette into a 0.2-ml thin-wall PCR tube contains lysis buﬀer. Library construction is done using SMART-seq2 protocol with minor modification.

Assay description

Two-condition experiment, early-onset PE (n=8) vs. late-onset PE (n=7).

Extraction protocol

Total RNA extracted using Trizol following manufacturer's instructions Label Cy3 Label protocol 5 µg of total RNA were labelled using Corning ChipShot labelling system following manufacturer's instructions. Main topic
This study investigates placental gene expression profiles in early- and late-onset pre-eclampsia to elucidate the differences between the two subgroups, using whole genome microarray technology and bioinformatic analysis.

Methods Assay, extraction, and data processing text

Assay description

Pregnant mice were exposed to benzo[a]pyrene, and gonads were collected from E13.5 embryos for RNA-seq.

Extraction protocol

Total gonads were subjected to total RNA isolation using QIAGEN RNeasy kit. cDNA was synthesized from total RNA using Takara SMART-Seq v4 Ultra Low Input RNA Kit for Sequencing with oligo(dT) priming. Libraries were prepared from sonicated cDNA using Takara Low Input Library Prep Kit.

Main topic
This study investigates the metabolic pathways active in the embryo and its developing gonads, and the mechanisms by which prenatal exposure to Benzo[a]pyrene (BaP) predisposes to ovarian tumors later in life. It uses RNA sequencing to identify transcriptomic changes in embryonic gonads of mice exposed to BaP.
